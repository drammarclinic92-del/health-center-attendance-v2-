
# نظام حضور وانصراف موظفي المركز الصحي

موقع ويب عربي لتنظيم حضور وانصراف موظفي المركز الصحي، مع واجهة متوافقة مع الهواتف وأجهزة الكمبيوتر.

## الهدف

- خدمة نحو 30 موظفًا.
- توفير بوابة إلكترونية للموظف.
- إنشاء لوحة إدارية لمتابعة الدوام.
- التخطيط للتحقق من هوية الموظف باستخدام الوجه.
- إعداد تقارير الحضور والانصراف والتأخير والغياب.

## الملفات الحالية

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `styles.css` | التصميم والتنسيق |
| `employee.html` | واجهة الموظف الأولية |
| `admin.html` | لوحة الإدارة الأولية |
| `README.md` | توثيق المشروع |

## الحالة الحالية

المشروع في مرحلة الواجهة الأولية.

الصفحات الحالية لا تسجل حضورًا حقيقيًا، ولا تتصل بقاعدة بيانات، ولا تنفذ تحققًا حقيقيًا من الوجه.

الأرقام المعروضة في لوحة الإدارة تجريبية وليست سجلات فعلية.

## مراحل التطوير القادمة

1. اختبار الواجهات على الآيفون والكمبيوتر.
2. إعداد قاعدة بيانات آمنة.
3. إضافة حسابات الموظفين والتحقق من هوياتهم.
4. بناء نظام تسجيل الحضور والانصراف.
5. إضافة صلاحيات الإدارة والتقارير.
6. اختبار الأمان والخصوصية قبل الاستخدام الفعلي.
7. نشر الموقع بعد اكتمال الاختبارات.

## الخصوصية والأمان

- لا ترفع صور الوجوه أو بيانات الموظفين الحقيقية إلى مستودع عام.
- لا تضع كلمات المرور أو مفاتيح الخدمات السرية في ملفات الواجهة.
- يجب حماية لوحة الإدارة بتسجيل دخول وصلاحيات من جهة الخادم.
- يجب الحصول على الموافقات اللازمة قبل معالجة البيانات البيومترية.
- يجب اختبار النظام على الأجهزة المستهدفة قبل الاعتماد عليه.

## التشغيل المحلي

يمكن فتح `index.html` في متصفح لمعاينة الواجهة الرئيسية.

يجب أن تكون الملفات الأساسية داخل المجلد نفسه حتى تعمل روابط الصفحات وملف التنسيق.

## النشر

يمكن استضافة الواجهة الثابتة على GitHub Pages بعد إعداد النشر.

GitHub Pages لا يوفر وحده قاعدة بيانات أو نظام تسجيل دخول آمنًا أو تحققًا من الوجه؛ هذه الخدمات تحتاج إلى مكونات خلفية منفصلة.
